# ASCEND testing & release checklist

## Automated (run before every release)
- [ ] `npm test` — all suites green
- [ ] `npm run typecheck`
- [ ] `npm run lint`
- [ ] `npx expo-doctor` (needs network)
- [ ] `npx expo export --platform web` bundles without errors (catches import/runtime issues quickly)

## Manual device test pass (one mid-range Android + one iPhone)
**Onboarding**
- [ ] Fresh install shows the welcome animation; reduce-motion (system) shows a static version
- [ ] Questionnaire: validation on name and days; "Under 13" blocks with a friendly message; 13–17 hides weight goals
- [ ] Analyzing screen → review; Edit (saves through validation), Rebuild, Accept
- [ ] Offline (airplane mode) onboarding still produces a plan ("ASCEND program engine")

**Training**
- [ ] Start a workout from Home (training day) and from Train (any day)
- [ ] Log sets with weight/reps/difficulty; undo; rest timer counts down, +15s, skip, sound + haptic at end
- [ ] Timed exercise: hold timer start/stop fills seconds
- [ ] Replace / Easier / Skip; open technique guide and coach mid-workout → return, nothing lost
- [ ] Kill the app mid-workout → reopen resumes the workout
- [ ] Finish → Mission Complete, XP count-up, celebration overlay (first workout achievement)
- [ ] Feedback with pain + area → plan swaps exercises (Train → Coach updates)
- [ ] Second workout the same day earns no workout XP (message explains why)

**Quests & progression**
- [ ] Check-in (< 1 min) awards XP once per day; updating does not re-award
- [ ] Mobility routine timer completes and awards XP; rest-day quests shown on rest days
- [ ] Weekly missions progress; level-up and rank promotion animations play once (test via several sessions or debug data)
- [ ] Cosmetics: locked items cannot be equipped; badges up to 3

**Progress & data**
- [ ] Charts empty-state before data; Week/Month/Year switch; strength chart after 2 sessions of a lift
- [ ] Body weight only for adults; delete entry
- [ ] Demo mode shows "DEMO DATA" labels everywhere and leaves real data untouched
- [ ] Export JSON opens the share sheet with a valid file

**Account (with Supabase configured)**
- [ ] Guest → AI coach replies tagged "AI COACH"; without network tagged "OFFLINE MODE"
- [ ] Create account from guest keeps history; sign out / sign in on a second device restores data
- [ ] Password reset with 6-digit code
- [ ] Delete account removes cloud rows and local data, returns to welcome

**Platform & accessibility**
- [ ] Safe areas on notch/punch-hole devices; small screens (iPhone SE) and large text (200%) don't clip critical buttons
- [ ] VoiceOver/TalkBack labels on tabs, steppers, ratings, charts (summaries)
- [ ] Sound/music/haptics toggles respected; music mixes with Spotify etc.
- [ ] Notifications: permission prompt only after enabling in Settings; reminders arrive at chosen times; disabling cancels them

## Store preparation
- [ ] Final bundle IDs in `app.json`; `eas init` done; version bumped (`autoIncrement` handles build numbers)
- [ ] App icon/splash reviewed on device (generated by `scripts/generate-icons.mjs`)
- [ ] Privacy policy & terms URLs (required by both stores) — describe: profile, training data, optional body weight, AI processing via Anthropic for coach requests, no ads/tracking
- [ ] Apple privacy nutrition labels: Health & Fitness data (linked to user, not used for tracking), Contact info (email), User content (coach chat)
- [ ] Google Play Data safety form consistent with the above; account deletion URL/instructions provided
- [ ] Age rating questionnaire (13+); Health/Fitness category; no medical claims in the listing
- [ ] If Apple/Google sign-in is offered, Sign in with Apple must be enabled on iOS (App Store guideline 4.8)
- [ ] Screenshots (6.7" and 5.5" iOS, phone Android), short & full description, feature graphic
- [ ] TestFlight / Internal testing round with real users, then production rollout (staged on Android)
