# Screenshots

Aufgenommen mit Playwright/Chromium während der Entwicklung (Desktop 1440 px, Smartphone 390 px).

**Wichtig:** In der Entwicklungsumgebung gab es keine GPU und keine Modelldownloads. Chat-Antworten („Echo from …“),
Bilder (einfarbige Platzhalter) und Videofortschritt in diesen Screenshots stammen von den **Protokoll-Testdoubles**
in `tests/` — nicht von einem KI-Modell. Sie zeigen die echte Oberfläche und den echten Ablauf (Streaming, Quellen,
Warteschlange, Fortschritt, Galerie). Mit Ollama/ComfyUI auf deinem PC erscheinen dort echte Antworten, Bilder und Videos.
